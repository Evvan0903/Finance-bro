# saveToken

Route work before doing it. Keep the assignment brief, reuse available context, and avoid loading the same material repeatedly.

## Routing

- **Sol**: task planning, architecture, difficult reasoning, financial judgment, conflict resolution, and final review.
- **Terra**: large-scale scraping, research, document extraction, data processing, classification, and repetitive analytical work.
- **Luna**: formatting, normalization, cleanup, file organization, routine summaries, and other simple, low-risk work.

## Workflow

1. Sol briefly decomposes a complex request into work units and assigns each unit.
2. Terra handles high-volume data, research, extraction, and repetitive analysis.
3. Luna handles simple organization, normalization, formatting, and presentation work.
4. Sol reviews only decision-critical, conflicting, or low-confidence outputs and performs the final review.
5. Use the least expensive capable model for each unit, and do not repeatedly reload unchanged context.

For small, low-risk requests, Luna may execute directly. Escalate to Sol when scope, judgment, or uncertainty becomes material; route data-heavy work to Terra before presentation or cleanup.
